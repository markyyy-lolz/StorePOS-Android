# StorePOS v1.3.8

StorePOS v1.3.8 introduces the new official StorePOS retail identity across the Android app.

## New StorePOS Branding
- Added the new blue-and-teal StorePOS shopping-bag and receipt logo.
- Replaced the previous launcher icon with the new StorePOS retail icon.
- Added the full StorePOS brand mark to the sign-in / owner account screen.
- Branding is optimized for Android tablet and dedicated POS terminal use.
- The new logo is prepared for reuse by the separate StorePOS Terminal Launcher project.

## Existing v1.3.7 Receipt Improvements
- Client store branding remains first on customer receipts.
- StorePOS branding stays subtle at the receipt footer.
- ORPH customer-facing payment label.
- Digital receipt QR code on supported ESC/POS thermal printers.
- Digital receipts expire after 3 days / 72 hours.

## Compatibility
- Android 8.0+ (minSdk 26)
- Package: `com.storepos.app`
- Version code: 13
- Version name: `1.3.8`
- Existing shops, products, sales, licenses, payment settings, and receipt tokens are preserved.
